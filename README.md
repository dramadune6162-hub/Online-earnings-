# From Hard Work to Smart Earning

A responsive, 30-second, 16:9 motion-graphics-style web animation for the Online Earnings channel.

## Preview
Open `index.html in a browser. The six scenes run automatically and loop; use Replay or Fullscreen for playback.

## Story
1. The daily grind
2. Money is still tight
3. Discovering online opportunities
4. Learning practical digital skills
5. Practicing and building a portfolio
6. The lesson: don't just work hard—learn to work smart

## Customize
Edit the text, emoji visuals, colors in the CSS variables, or scene timings in `index.html`.

Note: this repository contains an animated web preview/source project, not a rendered MP4 video. Record the preview with a screen recorder or use it as a reference for a video editor to produce an MP4.
